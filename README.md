# 🏺 陶艺拉坯实验 AI 智能辅助与标准化教学指导原型系统

> Pottery Throwing AI-Assisted Intelligent Tutoring System — Prototype

郑州西亚斯学院艺术设计学院 · AI+X 精英班

## 📖 项目简介

本系统是针对**陶艺拉坯实训教学**场景开发的轻量化 AI 辅助原型，由两个互补的子系统组成，覆盖拉坯成型全流程 **10 个核心环节**。

| 子系统 | 入口 | 定位 | 核心能力 |
|--------|------|------|----------|
| 🤖 **智能问答知识库** | `index.html` | 桌面端 · 课前/课后 | 50+ 问答对 · 全文搜索 · 知识导航 |
| 🎓 **AI 分步指导导师** | `guide.html` | 手机端 · 课堂实操 | 摄像头 · AI 语音 · 错误诊断 · 泥料适配 |

---

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/hery-2006/pottery-ai-assistant.git
cd pottery-ai-assistant

# 启动（任选一种）
python -m http.server 8080
# 或
npx serve . -p 8080
```

浏览器打开：
- 知识库：`http://localhost:8080/index.html`
- AI 指导：`http://localhost:8080/guide.html`

> ⚠️ **视频文件**需手动放入 `videos/` 目录，详见该目录下 `README.txt`。

### 智能问答系统（index.html）

| 功能 | 说明 |
|------|------|
| 🔍 智能搜索 | 关键词搜索，自动定位到相关步骤 |

| 📚 陶瓷小知识 | 侧边栏随机冷知识，点击刷新 |
| 📱 响应式适配 | 桌面双栏 + 手机抽屉式导航 |

### AI 分步指导导师（guide.html）

| 功能 | 说明 |
|------|------|
| 🖼️ CSS 器型线稿 | 10 种纯 CSS 绘制的陶瓷器型轮廓 |

| ✅ 进度追踪 | localStorage 持久化，10 步全完成展示庆祝卡片 |
| 🎬 教学视频 | 6 步配备独立教学视频，原生进度条可拖拽 |

## 📝 使用场景

- **A. 课前预习** — 手机打开知识库，浏览流程 + 阅读要点 + 提问预习
- **B. 课堂实操** — 手机打开 AI 指导 → 选泥料 → 进入 AI 导师模式 → 摄像头对准拉坯机 → 跟随语音操作
- **C. 课后复习** — 桌面端打开知识库，搜索回顾 + 查看文化延伸
- **D. 工坊自主练习** — 手机放在支架上，AI 语音 + 参考视频 + 错误诊断全程辅助
