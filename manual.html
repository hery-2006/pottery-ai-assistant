1. 系统概述

本系统是针对陶艺拉坯实训教学场景开发的轻量化AI辅助原型，由两个互补的子系统组成：

🤖

智能问答系统

覆盖拉坯全流程10个核心环节的标准知识库，支持关键词搜索和智能问答交互。适用于课前预习、课堂辅助、课后复习。

桌面端 手机端

🎓

AI分步指导导师

10步零基础入门引导，含摄像头实时画面、AI语音讲解、AI操作检查、高频错误诊断。适用于课堂实操、工坊自主练习。

手机端优先

核心指标

指标当前状态
知识点覆盖率10个环节100%覆盖，50+专业问答对
高频错误库25条常见错误 + 标准化纠正方案
泥料适配4种泥料（陶泥/精陶泥/瓷泥/紫砂泥）自动适配参数
响应式适配桌面端 + 手机端 + 微信内置浏览器
陶瓷文化元素五大名窑、古诗引用、文化延伸卡片

2. 系统一：AI知识库与智能问答

入口文件：index.html

2.1 界面布局

页面采用左侧导航 + 右侧内容的双栏布局：

区域功能
顶部 Header系统标题、AI知识库状态指示器
左侧栏 — 五大名窑色卡汝官哥钧定五窑釉色展示（装饰+文化）
左侧栏 — 搜索框关键词搜索，自动定位到相关步骤
左侧栏 — 流程导航10个步骤列表，点击切换，显示段位标签（段位一/二/三）
左侧栏 — 陶瓷小知识随机展示陶瓷冷知识，点击可刷新
右侧 — 详情卡片当前步骤的技法要点、注意事项、常见问答、文化延伸
右侧 — 聊天面板欢迎面板（古诗引用+精选问题+段位导航）、智能问答对话、推荐问题

2.2 核心功能

🔍

智能搜索

在搜索框输入关键词（如"气泡""转速""上釉"），自动匹配并跳转到相关步骤

💬

智能问答

输入问题获取AI回答。支持50+预设问答对，基于关键词匹配和语义评分

📋

推荐问题

每个步骤提供4个高频推荐问题，一键点击即可获取答案

🎨

釉色色卡

上釉步骤专属：6种常见釉色的可视化色卡展示

📖

文化延伸

每个步骤关联一条陶瓷文化知识（如"牛毛揉"典故、"风火仙师"传说）

📱

手机适配

768px以下自动切换为移动布局，侧边栏变为滑出抽屉

2.3 操作指南

  1. 浏览知识库：点击左侧流程列表中的任意步骤，右侧显示该步骤的技法要点、注意事项和常见问答
  2. 搜索：在搜索框中输入关键词，系统自动定位到最相关的步骤
  3. 提问：在聊天输入框中输入问题（如"揉泥有什么技巧？"），按回车或点击发送
  4. 快速提问：点击聊天区下方的推荐问题按钮，一键获取答案
  5. 查看文化知识：展开详情卡片底部的"文化延伸"卡片，阅读相关陶瓷文化典故
  6. 刷新知识：点击侧边栏底部的"陶瓷小知识"区域可切换展示内容

3. 系统二：AI分步指导导师

入口文件：guide.html（主要面向手机端使用，桌面端自动适配 480px 宽度）

3.1 界面布局

区域功能
顶部 Header系统标题、泥料选择按钮
IP横幅局域网地址提示（手机扫码访问用）
进度条10步进度圆点（显示数字/✓），点击切换步骤
步骤卡片区可左右滑动切换，每步包含器型线稿、操作说明、视频、AI指导按钮
装备参数栏当前步骤的转速/水量/工具/耗时推荐值
底部导航栏首页/目录/求助/真人连线
AI导师浮层全屏深色模式，含摄像头+参考视频+AI聊天+语音讲解+AI检查+快捷提问

3.2 核心功能

🖼️

CSS器型线稿

每步卡片顶部展示纯CSS绘制的陶瓷器型轮廓（球形→锥形→直筒→花瓶→碗形…），直观展示当前步骤的造型目标

📷

AI面对面指导

进入全屏AI导师模式：后置摄像头实时画面 + 参考视频画中画 + AI文字指导 + AI语音讲解

🎤

AI语音讲解

自动朗读当前步骤的完整操作说明，支持多种中文语音（取决于浏览器）

👀

AI操作检查

每个步骤提供自查问题，根据回答给出通过提示或纠正建议

🆘

错误诊断

求助菜单内置25条常见错误，支持关键词搜索，每条含严重等级、立即行动、分步纠正方案、教师提醒

🏺

泥料参数适配

选择泥料类型后，转速推荐值自动按系数调整，参数栏实时更新

📞

真人教师连线

通过Jitsi Meet建立视频通话，教师可远程实时指导

✅

进度追踪

完成每一步后标记，进度保存到本地。全部10步完成后展示庆祝卡片+陶瓷名句

3.3 操作指南

  1. 选择泥料（推荐首次使用）：点击右上角"选择泥料"，在弹出面板中选择所用的泥料类型，系统自动适配转速等参数
  2. 左右滑动切换步骤：在步骤卡片区域左右滑动（或按键盘 ← → 键），浏览10个步骤
  3. 观看教学视频：有视频的步骤（揉泥、定中心、拉高、修坯）可直接在卡片内播放
  4. 进入AI指导模式：点击紫色"进入AI面对面指导模式"按钮，进入全屏AI导师界面
  5. 查看子步骤：在AI导师界面底部，横向滑动查看当前步骤的子步骤，点击切换
  6. AI语音讲解：点击"讲解"按钮，AI自动朗读当前步骤的操作说明
  7. AI检查：点击"AI检查"按钮，回答自查问题，获取反馈
  8. 提问AI：在底部输入框打字提问，或点击快捷回复按钮
  9. 遇到问题：点击底部"求助"→ 搜索症状关键词 → 查看分步纠正方案
  10. 完成步骤：点击"完成"按钮标记进度，弹出陶瓷文化小贴士
提示：AI导师模式下，手机摄像头默认开启后置（对着拉坯机方向），左下角播放参考教学视频。这对于在工坊实操时"边看边做"非常实用。

4. 数据与知识库说明

4.1 知识库结构

数据文件内容条目数
knowledge-base.json全流程知识库（内嵌于index.html的KB对象）10步 × N条QA
data/clay-types.json泥料类型与参数特性4种
data/equipment.json每步的推荐设备参数10条
data/errors.json高频错误与纠正方案25条
data/step-guidance.json分步子步骤操作说明10步 × N子步骤

4.2 错误库覆盖范围

25条错误按严重程度分级：

  • 严重 (Critical) — 长发未扎、水洒电机、素烧炸坯（3条）
  • 高 (High) — 泥团晃动、开孔偏斜、穿底、泥壁塌陷、忘擦底釉等（9条）
  • 中 (Medium) — 粘手、转速不当、壁厚不均、不对称、开裂等（11条）
  • 低 (Low) — 不确定干湿、不确定窑门关闭时机（2条）

5. 使用场景与操作流程

场景A：课前预习

目标：学生在上课前了解本次实训的核心步骤和理论知识

推荐工具：智能问答系统（index.html）

推荐设备：手机或电脑

  1. 打开智能问答系统，浏览左侧流程导航了解全流程概况
  2. 点击本次课程涉及的步骤，阅读技法要点和注意事项
  3. 点击推荐问题或输入自定义问题，预习常见疑问
  4. 查看"文化延伸"卡片，加深对陶瓷工艺的理解

场景B：课堂教学辅助

目标：教师在课堂示范时辅助讲解，学生在实操时自主获取指导

推荐工具：智能问答（桌面端）+ AI分步指导（手机端）

推荐设备：教室大屏 + 学生手机

  1. 教师在大屏上打开智能问答系统，配合示范讲解流程知识
  2. 学生用手机打开AI分步指导，选择泥料后进入对应步骤
  3. 实操时开启AI导师模式，摄像头对准拉坯机，语音讲解同步播放
  4. 遇到问题时使用"求助"菜单搜索错误症状
  5. 完成一步后点击"完成"标记，教师可查看整体进度

场景C：课后工坊自主练习

目标：学生在无教师在场的情况下独立练习

推荐工具：AI分步指导（guide.html）

推荐设备：手机（放置在拉坯机旁支架上）

  1. 打开AI分步指导，选择泥料类型
  2. 从上次完成的步骤继续，点击"进入AI面对面指导模式"
  3. 将手机放在支架上，后置摄像头对准双手和拉坯机
  4. 参考左下角教学视频，跟随AI语音讲解操作
  5. 每完成一个子步骤，使用AI检查功能自评
  6. 遇到不确定的情况，在快捷回复中提问或搜索求助
  7. 如需真人帮助，点击"真人连线"建立视频通话

场景D：教师备课与学情诊断

目标：教师提前了解学生预习情况，准备针对性教学

推荐工具：智能问答系统 — 学生提问记录 + 高频问题统计

（注：当前v1.0版本暂不支持数据分析后端，可在后续版本中加入。）

6. 技术环境与部署方式

6.1 技术栈

层级技术
前端框架纯 HTML + CSS + JavaScript（无依赖）
语音合成浏览器 Web Speech API（SpeechSynthesis）
摄像头浏览器 MediaDevices API（getUserMedia）
视频通话Jitsi Meet（开源视频会议）
数据存储localStorage（学习进度本地持久化）
部署方式任意HTTP服务器（Python/Node.js/Nginx/GitHub Pages）

6.2 本地运行

方法一：Python HTTP服务器

cd 陶艺项目 python -m http.server 8080

然后浏览器打开 http://localhost:8080/index.html 或 http://localhost:8080/guide.html

方法二：Node.js

npx serve . -p 8080

方法三：GitHub Pages（在线部署）

将项目推送到GitHub仓库，在Settings → Pages中启用，选择main分支部署。部署后可通过 https://用户名.github.io/pottery-ai-assistant/ 访问。

6.3 手机端访问

电脑启动服务器后，手机连接同一WiFi，浏览器访问电脑的局域网IP地址。系统顶部会自动显示IP横幅，点击可复制链接。

注意：AI导师模式的摄像头功能需要HTTPS或localhost环境。在局域网HTTP环境下，部分浏览器可能限制摄像头访问。

7. 常见问题

Q: 两个系统有什么区别？什么时候用哪个？

A: 智能问答（index.html）侧重知识查询和学习，适合课前预习和课后复习。AI分步指导（guide.html）侧重实操引导和即时纠错，适合课堂练习和工坊自主练习。

Q: AI检查能真的看到我的操作吗？

A: 当前v1.0版本的AI检查是自查问答模式——系统提出问题，学生根据自己的操作情况选择答案，然后给出反馈。暂不支持计算机视觉自动识别。这是文档中明确限定的范围。

Q: 如何更新知识库内容？

A: 知识库数据内嵌在两个HTML文件的JavaScript对象中（KB和EMBEDDED）。修改时直接在HTML文件中找到对应数据对象编辑即可。JSON数据文件（data/目录下）为结构化参考。

Q: 语音讲解没有声音怎么办？

A: 1) 检查设备音量；2) 部分浏览器需要用户首次交互后才能启用语音（点击页面任意位置）；3) 微信内置浏览器对TTS支持有限，建议在系统浏览器中打开。

Q: 教学视频文件在哪里？

A: 视频文件位于videos/目录下，包括揉泥、定中心、拉高、修坯的示范视频。由于文件较大（160MB+），未上传至Git仓库，需要在本地videos/目录中放置对应的mp4文件。
